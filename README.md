# Cálculo Numérico — UESC

Implementações em Python de métodos estudados na disciplina de Cálculo Numérico.

- **Busca de raízes** — bissecção, posição falsa, Newton–Raphson e secante.
- **Sistemas lineares e matrizes** — eliminação de Gauss, fatoração LU, inversão por Gauss–Jordan e LU, Jacobi e Gauss–Seidel.

Os métodos estão em [PARTE I](PARTE%20I/), em pastas separadas. Consulte o script e o arquivo `entrada.txt` do método escolhido antes de executá-lo. As pastas também guardam exemplos de resultados quando disponíveis.
